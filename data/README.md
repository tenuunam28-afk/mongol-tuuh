# Өгөгдөл

- `eras.json` — үе бүрийн нэр, он, товч тайлбар, үйл явдал, түүхэн хүмүүс.
- `borders.json` — газрын зургийн хил хязгаар. [aourednik/historical-basemaps](https://github.com/aourednik/historical-basemaps)-ийн GeoJSON-оос `tools/build_borders.py` скриптээр ялгаж, монгол нэр өгсөн. Эх өгөгдөл GPL-3.0 лицензтэй тул энэ файл мөн GPL-3.0 (`LICENSE-borders.txt`).
- `land.json` — газрын зургийн хуурай газар, том нуурууд. [Natural Earth](https://www.naturalearthdata.com)-ийн 1:50м өгөгдлөөс `tools/build_land.py` скриптээр бэлтгэсэн (нийтийн өмч).

Хил хязгаар ойролцоо бөгөөд үе бүрийн нэг оны байдлыг харуулна.
